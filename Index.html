About the System

The Hausa Based Spam Detector is a system designed to identify potentially unwanted Hausa online messages. It provides a simple interface where a user can enter a Hausa message and receive a classification as spam or not spam.

The project applies Natural Language Processing (NLP), TF-IDF feature extraction, and a Naïve Bayes classification approach as part of the proposed spam detection methodology.
